### 🔒 互斥性保证机制

| 保证层级   | 实现位置                            | 说明                                           |
| ---------- | ----------------------------------- | ---------------------------------------------- |
| **配置层** | `RolloutConfig.cvae_branching_mode` | 只能设置一个值                                 |
| **验证层** | `validate_z_injection_config()`     | 创建配置时强制验证                             |
| **数据层** | `ZInjectionConfig`                  | 只有一个字段有值                               |
| **模型层** | `qwen2.py`, `qwen3.py`              | `if mode == "input"` vs `if mode == "softmax"` |
| **日志层** | 各处日志                            | 明确显示哪个模式生效                           |

---

### 🎯 四种模式对比

| 模式        | z 使用 | 实现方式                        | 互斥性                      |
| ----------- | ------ | ------------------------------- | --------------------------- |
| **random**  | ❌      | 不注入，完全随机                | ✅ 与其他模式隔离            |
| **input**   | ✅      | ForwardContext + Qwen2Model     | ✅ 与 softmax 互斥           |
| **psa**     | ✅      | PyTorch hook（独立机制）        | ✅ 不使用 z_injection_config |
| **softmax** | ✅      | ForwardContext + compute_logits | ✅ 与 input 互斥             |
